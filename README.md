## 作り方

文章は `data/*.json`、見た目は `src/style.css`、動きは `src/main.js`、組み立ては `build.py`（Python の標準機能だけ）。
ページの HTML を直接書き換えず、元のファイルを直してから作り直す。

```sh
python3 build.py                 # 確認用を、この場所（リポジトリ直下）に書き出す
python3 build.py --release       # 公開用を dist/ に書き出す。確認が残っていれば一覧を出して止まる
python3 build.py --release --force --site-url https://www.marushin-kaitai.com
```

確認用と公開用の違い

| | 確認用 | 公開用（`dist/`） |
| --- | --- | --- |
| 「制作中のページです」の帯 | 出る | 出ない |
| 検索に載せない設定（noindex） | 入る | 入らない |
| 黄色の「要確認」の印 | 出る | 出ない |
| 写真の仮枠 | 出る | 出ない |
| `check.html` | 作る | 作らない |
| URL を貼ったときの写真（OGP画像）の場所 | 確認用の github.io | `--site-url` のアドレス（無ければ出さない） |

LINE などに URL を貼ったときに出る写真は `images/ogp.jpg`（1200×630）。トップの最初の画面を `python3 ogp.py` で撮って作る。
トップの写真や見出しを変えたら撮り直してから `build.py` を流す。

`raw/`（今のサイトを保存したもの）と `dist/` は、この置き場所には上げない。

確認用のページの右下に「色を選ぶ」ボタンがある（公開用には入らない）。案は `build.py` の `THEMES` の7種類（2026-11-20 に4→7）。

決まったら、その案の色を `src/style.css` の `:root` に移し、`THEMES` と切り替えの部品を外す。
